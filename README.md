# ProNext IT Redesign

A responsive B2B website redesign for an IT services company, focused on clear service positioning, lead generation, case-study storytelling, and a polished customer-facing experience.

## Highlights

- Multi-page TanStack Start website with routes for home, services, case studies, careers, about, and contact.
- Reusable header, footer, theme, and UI components built for consistency across customer pages.
- Lead-generation focused layout with service sections, credibility signals, and structured calls to action.
- Responsive visual system using Tailwind CSS, Radix UI primitives, lucide icons, and motion-enhanced interactions.

## Stack

TanStack Start, React, TypeScript, Vite, Tailwind CSS, Radix UI, shadcn-style components, Framer Motion, Vercel.

## Scripts

```bash
npm install
npm run dev
npm run build
```
